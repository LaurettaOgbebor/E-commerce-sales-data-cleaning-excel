# Project Overview
This project focuses on cleaning and preparing a raw e-commerce sales dataset for analysis using Microsoft Excel. The goal was to improve data quality, ensure consistency, and create an analysis-ready dataset while documenting every change made.

# Dataset
- Records: 1,200
- Tool Used: Microsoft Excel
- Industry: E-commerce / Retail

 # Data Cleaning Tasks Performed
- Filled 309 missing coupon code values with "No Coupon"
- Standardized the Date column to ISO 8601 format (YYYY-MM-DD)
- Verified all Order IDs for uniqueness (1,200 unique records)
- Checked the dataset for duplicate rows and confirmed none existed
- Created a separate Change Log sheet to document all cleaning actions
